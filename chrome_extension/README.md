# アニソンプレーヤー 歌詞位置連携（Chrome 拡張機能）

プレーヤーの「歌詞・コード」パネルで歌ネット（歌詞・コード）や ChordWiki のページを開いたとき、
そのページの歌詞部分の上端と下端の位置を、プレーヤーに数値で知らせます。

- 歌ネット：`id="kashi-box"` の枠
- ChordWiki：`body > div.main`（歌詞とコードが入っている部分）

プレーヤーはその位置を使い、動画の最初から最後にかけて歌詞全体が流れるように自動スクロールします
（動画の最後に、歌詞部分の終わりがパネルの上から 2/3 あたりに来ます）。
また、歌ネットにコードのページが無い曲では、それをプレーヤーに知らせ、歌詞のページに自動で切り替えてもらいます。

- 動くのは、プレーヤー（`http://localhost` のローカル版と `https://asayake0840.github.io` の公開版）のパネル内で開かれたときだけです。普通のタブで開いた歌ネットなどでは何もしません。
- 送るのは位置の数値・コード譜の有無・ページのアドレスだけで、歌詞などの内容は送りません。ページの表示も変えません。
- 外部への通信や、閲覧履歴などの読み取りはしません（特別な権限も要求しません）。

## 入れ方（最初に1回だけ）

1. このフォルダ（zip でダウンロードした場合は展開したフォルダ）を、消さない場所に置きます。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` が入っているフォルダを選びます。
5. 一覧に「アニソンプレーヤー 歌詞位置連携」が出れば完了です。プレーヤーのページを再読み込みしてください。

パネルの説明文が「歌詞の枠の位置を取得しました。」になっていれば連携できています。

## 更新したとき

フォルダの中身を新しいものに置き換えてから、`chrome://extensions` で「アニソンプレーヤー 歌詞位置連携」の
再読み込みボタン（円形の矢印）を押してください。

## 外し方

`chrome://extensions` で「アニソンプレーヤー 歌詞位置連携」の「削除」を押します。
