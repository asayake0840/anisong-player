# アニソンランキング プレーヤー（1960–2026）

Billboard JAPAN「Hot Animation」の年間チャート（2026年は上半期チャート）をもとにしたアニソンのランキングを、
ページ内の YouTube プレーヤーで連続再生できるページです。

**ページ：** https://asayake0840.github.io/anisong-player/

- 累計（2022〜2026年）、2026〜2010年の各年（各100曲）、年代別（2010年代〜1960年代）のランキングがあります。
- 2011〜2026年の各年1〜20位は Billboard JAPAN の公式順位、21〜100位は推定の参考順位です。2010年と年代別はすべて推定です（ページでは「推定」と表示）。
- 検索窓では、すべてのランキングから曲名・歌手・作品で探せます。
- 曲ごとの長さ、OP／ED／主題歌／挿入歌、歌詞・コードのページの有無のチップ、再生中の曲の画像を使った背景、音量・再生位置の操作があります。
- 「歌詞・コード」パネルで、歌ネット（歌詞・ギターコード）・ChordWiki・U-FRET のページを開き、再生に合わせて自動スクロールできます（拡張機能が無いスマホなどでは、おおよその位置でのスクロールになります）。

## 歌詞の自動スクロールを正確にする拡張機能（Chrome）

拡張機能を入れると、パネル内の歌ネット・ChordWiki のページから歌詞部分の位置を受け取り、
動画の最初から最後にかけて歌詞がぴったり流れるようになります。
歌ネットにコードのページが無い曲では、自動で歌詞のページに切り替わります。
U-FRET では外部の広告枠を非表示にし、ギター／ウクレレ／ピアノ／ベースの表示を選べます。
（U-FRET は広告収入で無料提供されているサイトで、広告なしで使える有料プラン「U-FRETプレミアム」もあります。）

1. [anisong-lyrics-extension.zip](anisong-lyrics-extension.zip) をダウンロードして、消さない場所に展開します。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダ（`manifest.json` が入っているフォルダ）を選びます。
5. プレーヤーのページを再読み込みします。

拡張機能はプレーヤーのパネル内で開いたページでだけ動き、歌詞部分の位置（数値）とコード譜の有無だけをプレーヤーに知らせます（U-FRET では広告枠の非表示と楽器の切り替えも行います）。
歌詞などの内容は送らず、特別な権限も使いません。詳しくは [chrome_extension/README.md](chrome_extension/README.md) を見てください。

## 注意

- 歌詞・コード譜は各サイトのページをそのまま表示しています（このページには取り込んでいません）。
- 動画は YouTube 上の公式動画を埋め込んでいます。埋め込みが許可されていない動画は自動で飛ばします。
